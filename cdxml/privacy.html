3. File selection and system permissions

The app uses Android's document picker and files actively shared to it by other apps. It reads the selected or received file to process it, rather than scanning the whole device. Providers may be local storage, removable storage or cloud services.

4. Local processing and cloud snapshots

Parsing, display and PDF generation occur on-device. Imported original-byte copies support reopening and sharing. Reading and PDF export do not overwrite the source; the app does not pass documents, document content or hashes to Google SDKs or developer servers.

Cloud providers must first download unavailable cloud files under their own account, network and privacy terms. Imported copies are snapshots, without automatic updates after cloud edits or developer-server synchronization of recents. The app provides no remote conversion, cloud parsing or cloud document backup.

Font management is optional: use system fonts, select local TTF/OTF files, or tap to download recommended open-source fonts. Recommended fonts come from pinned GitHub raw-resource URLs over HTTPS, with size and integrity checks before activation. Reading documents, importing fonts or opening font management does not itself trigger font downloads. Installed fonts and substitution settings stay on-device for offline use, affect only in-app drawing and PDF, and do not change system fonts or original CDXML family names.
